## 接下来怎么做

教程第 2 节的选样与复制已完成，不必重新创建样本目录。你继续完成 [完整教程](OBSIDIAN_RAG_V2_GUIDE.md) 第 3 节，然后按第 4 节创建并运行 `prepare_notes_v2.py`，先检查预览、诊断与来源行范围，再继续建库。

选样优先覆盖小规模学习所需的结构，并不代表全库分布。首轮没有加入整页 HTML、大型 Python 函数文件、真实认证字段或客户报告；这些边界留到后续单独补样。代码笔记、剪藏和历史日志的技术正确性/当前适用性没有在本轮核验。

检索阶段可先试这些问题，不要求你先手写完整标准答案：

- “git clone 和 git pull 有什么区别？”——查看短对比是否共同返回。
- “PoC 是什么缩写？”——查看 Wordlist 对应行是否带列标题。
- “为什么 join 拼接数字列表会报错？”——查看条件、错误示例和修正是否关联；若围栏诊断导致跳过，先处理副本或明确记录未覆盖。
- “子包不同分支返回不同变量，主包调用时报未初始化，笔记怎么记录的？”——检查是否带回前提与结论。
- “我的笔记怎样描述 Parser？”——查看 10 月 27 日日记，避免夹入无关业务事项。
- “类的三种方法分别是什么？”——纯链接副本没有目标正文，不能仅凭链接名声称资料完整。
- “我在 2035 年第一次火星旅行的航班号是什么？”——人为设置的语料外问题，检查是否编造。
